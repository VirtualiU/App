# App de Atendimento Pós-venda

Landing page estática inspirada na página de atendimento pós-venda do Grupo Adel.

## Executar localmente

```bash
python3 -m http.server 4173
```

Abra: `http://localhost:4173`

## Estrutura

- `index.html`: estrutura da página
- `styles.css`: estilos e layout responsivo
- `script.js`: validação simples de formulário
